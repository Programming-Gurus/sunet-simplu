# Sunet Simplu

Plays the music of a theatre play, one step at a time, with fades. By Programming Gurus.

[DESIGN.md](DESIGN.md) describes what the app does and why. Read it first.

## Human note

Other than this section, most of this repo was generated by AI, based on a concept I (@vladutcornel) provided.  
I was asked by my acting school to handle lights and sound for theatre plays. They already had an overly convoluted app for lights. 
I prefer simple (to use) apps, like the ones we build at **Programming Gurus**.
They had nothing for sound. I didn't have time to learn a real app used in the industry, so I asked my AI assistant to build an app for the sound. 
I gave it instructions on how I wanted it to work and this is the result.

My AI assistant knows a lot about me, including the private acting school I attend, called "Teatru Simplu" (English: "Simple Theatre"),
so it suggested the name "Sunet Simplu" ("Simple Sound").

I am a programmer. I don't usually do vibe codding, but I needed this app quicker than I could build it myself. 
Even though I spent a few hours of my Claude usage, I am releasing the code for free because I won't take credit for something made by AI. 
You are free to use this project [as you want](LICENSE).

You can learn from it, because it uses some of the standards we have, 
which I taught my AI assistant (Yes, my AI assistant is capable of learning).

You can build it and use it if you ever end up in a position such as mine.
Or you can fork it to match your needs.

BTW, I've used it at several plays already, and it saved me a lot of time. I might update it as I see the need.

## Run

Needs Node 24 (`.nvmrc`; with nvm, run `nvm use`).

```bash
npm install
npm run dev
```

A development run keeps its projects in the folder "Sunet Simplu Dev", away from the installed app.

## Check

```bash
npm run typecheck   # types
npm test            # unit tests of the rules that need no sound
npm run selftest    # the app drives itself, hidden and silent, on a temporary data folder
```

Set `SUNET_SELFTEST_OUT` to a folder to get pictures of the screens from the self-test.

## Build the Mac installer

```bash
npm run dist:mac
```

The result is `dist/Sunet Simplu-<version>-arm64.dmg`. It has a local signature only. On a Mac that did
not build it, approve the app one time: System Settings, Privacy & Security, "Open Anyway".

Set `APP_BUILDS_DIR` to a folder, and the build also copies the installer to its subfolder `Sunet Simplu`,
for example a shared folder from which other computers install the app. Without it, the installer stays in `dist`.

## Layout

| Folder | Content |
|---|---|
| `src/main` | Main process: window, permissions, projects on disk, export and import. |
| `src/preload` | The bridge between the interface and the main process. |
| `src/renderer` | The interface (Vue 3). `lib/engine.ts` is the sound of the main output, `lib/preview.ts` the preview. |
| `src/shared` | Data shapes and the rules that need no sound or screen. |
| `tests` | Unit tests. `tests/fixtures` holds project files that older versions wrote. |
| `spike/audio-test` | The throwaway test that proved the audio-device assumptions. |
